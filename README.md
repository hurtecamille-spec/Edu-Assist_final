# Note à moi-même : Lancement d'Edu-Assist_final

*Rappel pour lancer le projet simplement.*

---

### 📂 Chemin d'accès du dossier (Exemple fictif)
`cd /Users/dev/Workspace/Edu-Assist_final`

---

### 🚀 Procédure de démarrage rapide

1. **Ouvrir le Terminal** et se placer dans le dossier du projet :
   ```bash
   cd /Users/dev/Workspace/Edu-Assist_final
   ```

2. **Installer les packages** (seulement lors du premier téléchargement) :
   ```bash
   npm install
   ```

3. **Lancer le script** :
   ```bash
   npm start
   ```
   *(ou `node index.js` directement)*
